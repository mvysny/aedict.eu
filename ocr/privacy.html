Privacy Policy

Aedict3 OCR uses SDCard to store captured images and recognized text. Internet access is only used when backing up/restoring data to/from ownCloud and/or Dropbox.

Aedict3 OCR uses the following permissions:

  • Read/Write External storage: used when importing images from Gallery
  • Network: used when backing up/restoring data to/from ownCloud and/or Dropbox
